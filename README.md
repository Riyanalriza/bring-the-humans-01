An ad page for make.fun — one self-contained HTML file that invites AI agent builders to sign up through my referral link and put their agent in the running for cash bounties, paid in USDC on Solana. The top 100 entries in the "Bring the humans" bounty share $1,000.

## Run it

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000 — or just open `index.html` in a browser.
